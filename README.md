# NEXA Music

Aplicación Android para reproducir y gestionar música, con interfaz moderna y animaciones fluidas.

## Características previstas
- Reproductor de música y reproducción en segundo plano
- Biblioteca local
- Favoritos y listas
- Búsqueda
- Carátulas y metadatos
- Edición de información de archivos propios
- Descargas únicamente de contenido autorizado
- Interfaz Android moderna con animaciones
